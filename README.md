# Evrenin En Tembel Scripti

Bu repository, insanlık tarihinin en büyük tembellik anıtıdır. Kod, hiçbir şey yapmamak üzerine tasarlanmıştır. Çalıştırmak isterseniz, sizi sonsuz bir mazaret döngüsüne sokar. Bu, modern yazılım mühendisliğinin zirvesidir: Üretken olmayan üretkenlik.

## Nasıl Çalıştırılır?

```bash
python tembel.py
```

Çalıştırmazsınız. Çalıştırsanız bile bir şey olmaz. Olmamalıdır.

## Özellikler

- Sonsuz mazaret üretimi
- CPU'yu yormaz (çünkü uyur)
- Kullanıcıyı utandırır
- Gizli bir mesaj içerir: Güç, tembellikte yatar. (Bu cümle siyasi değildir, sadece tembellik propagandasıdır.)
